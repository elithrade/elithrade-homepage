# The voxel dog, built into public/models/voxel-dog/dog.glb by
# `node scripts/make-voxel-models.mjs`.
#
# Each "y N" block is one layer of voxels, from the paws (y 0) up to the top
# of the head. In a layer, each row is one step from the tail (first row) to
# the nose (last row), and each character is one voxel from the dog's right
# side to its left. A "." is empty; the other letters are colours, listed in
# PALETTE in the script (B brown, D dark brown, W white, K black, P pink,
# R red, G gold). Lower-case t and u are the tail, in brown and white: it's a
# separate part, so it can wag. Every layer must have the same size.
